# Contributing to Claude Code Ecosystem Hub

Thank you for helping grow the open-source Claude Code ecosystem! We welcome contributions from developers, maintainers, and community creators.

---

## What Can You Submit?

- **New MCP Servers:** Any working Model Context Protocol server that extends agent capabilities.
- **`CLAUDE.md` Templates:** High-quality project instructions for specific frameworks, languages, or testing paradigms.
- **Workflows & Hooks:** Scripts or automation hooks that streamline building with Claude Code.

---

## Quick Submission Process

1. **Fork** the repository to your GitHub profile.
2. **Create a feature branch:**
   ```bash
   git checkout -b add-my-mcp-server
   ```
3. **Add your entry:**
   - If adding a tool or server, insert a new row in alphabetical order into `README.md`.
   - If providing a full framework rule set, add a markdown file into the `rules/` directory and link it from `README.md`.
4. **Commit your changes:**
   ```bash
   git commit -m "feat: add [Name] to MCP servers list"
   ```
5. **Open a Pull Request:**
   - Give your PR a clear title.
   - Describe what the tool or rule does.

---

## Inclusion Guidelines

To maintain directory quality:
- The project must be functional and publicly accessible.
- Repository links must lead to valid open-source repositories or official documentation.
- No spam or low-effort auto-generated links.

We aim to review and merge all valid community contributions within 24 to 48 hours.
