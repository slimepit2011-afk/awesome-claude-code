Instructions for Claude Code when developing modern React applications with Vite and Tailwind CSS.

```markdown
# React + Vite Guidelines

## Technology Stack
- React 18 / 19 with TypeScript
- Vite for fast local bundling
- Tailwind CSS with Lucide React for iconography
- Vitest for unit and component testing

## Core Engineering Standards
- Keep components modular and single-responsibility in `src/components/`.
- Prefer custom hooks for complex business logic, placed in `src/hooks/`.
- Ensure all forms have client-side input validation and graceful error feedback.
- Preserve existing comments and type interfaces when refactoring.

## Commands
- Start dev server: `npm run dev`
- Run test suite: `npm test`
- Production build check: `npm run build`
```
